# 🚴 Bike Sales Dashboard | Excel Data Analytics Project

An interactive **Bike Sales Dashboard** built in Microsoft Excel to analyze customer demographics, income patterns, and purchasing behavior. This project demonstrates data cleaning, pivot table analysis, and dashboard development using Excel.

## 📌 Project Overview

The goal of this project is to identify the factors that influence bike purchases by analyzing customer data. The dashboard provides business insights through interactive visualizations and KPI reporting.

## 🎯 Objectives

- Clean and prepare raw customer data
- Analyze bike purchasing trends
- Compare income by gender and purchase status
- Segment customers by age, education, occupation, and region
- Create an interactive dashboard using Pivot Tables and Slicers

## 🛠️ Tools & Skills

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Dashboard Design
- Business Data Analysis

## 📊 Dashboard Features

- Gender-wise bike purchase analysis
- Average income comparison
- Customer age segmentation
- Commute distance insights
- Regional sales analysis
- Interactive filters using slicers

## 📁 Dataset

- **Records:** 1,000 customers
- **Attributes:** 14 columns
- Includes demographics, income, education, occupation, commute distance, and bike purchase status.

## 💡 Key Insights

- Customers with higher average incomes showed a greater likelihood of purchasing bikes.
- Middle-aged customers represented the largest purchasing segment.
- Commute distance and occupation influenced purchasing behavior across regions.
- Interactive filtering enables quick business decision-making.
